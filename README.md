### SoloScale AI OS

**SoloScale AI OS** is a local-first, human-controlled AI workflow system that turns real engineering work into reusable evidence, learning, resume/application, and content artifacts.

It explores a practical architecture for applied AI:

**real work → evidence → retrieval → model reasoning → validation → human review → reusable artifact**

Key engineering areas include:

* bounded agent and workflow orchestration
* RAG and evidence retrieval over engineering artifacts
* structured LLM outputs and deterministic validation
* resume, application, learning, and content workflows over shared evidence
* local and hosted model integrations
* OAuth-based external integrations and publishing flows
* CLI, local web UI, macOS desktop, and video-generation surfaces
* pytest, Ruff, mypy, and deterministic acceptance checks

**Stack:** Python 3.11+ · Pydantic · Typer · SQLite / FTS · Ollama · MLX · OpenAI-compatible providers · Google APIs · SwiftUI · Remotion

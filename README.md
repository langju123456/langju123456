### Research Chain

Research Chain integrates SoloScale retrieval, ForgeFlow execution, and EvidenceLoop evaluation into one inspectable task. A local Qwen model selects search, verify, and finish. Numerical verification uses actual MCP stdio and a restricted Docker sandbox; calculation records are derived from successful execution receipts.

Successful and failed runs are preserved in an offline interactive viewer. The current sources are synthetic. The implementation remains private, so I describe the work here without presenting an inaccessible repository link as a public demo.
